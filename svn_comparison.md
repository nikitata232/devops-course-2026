## GIT VS SVN

1.  Приведу аналогию с книгой
    В git ветка - просто закладка в твоей книге, если ты хочешь что-то дописать, ты берешь и дописываешь сразу после закладки.
    В SVN ты не можешь так сделать, тебе для начала нужно сделать полную ксерокопию всей книги, чтобы что-то вписать.

2.  Без интернета работу в SVN не сохранить, так как ему нужно всегда обращаться к главному центральному серверу по интернету.
3.  SVN любят за то, что если тебе нужно скачать какой-то кусок из репозитория, отдельный файл, ты можешь это сделать. В git ты должен скачать весь файл для этого. + SVN более спокойно реагирует на тяжелые файлы.
